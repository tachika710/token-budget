# 《星海远征》游戏企划书 v0.3

> 用作 token-budget 工具的演示输入。可让 AI 调用 `estimate-cost` 估算分析 / 改写本企划书的成本。

## 1. 项目概述

### 1.1 一句话定位
《星海远征》是一款**科幻 4X 策略 + 角色养成**融合的手游，玩家扮演星际拓荒舰队指挥官，在 procedurally generated 的星系中探索、扩张、开发和征服。

### 1.2 核心循环
```
探索 → 资源采集 → 殖民建设 → 舰队扩张 → 战斗 → 战利品 → 升级 → 再探索
         ↑________________________________________________↓
```

### 1.3 商业目标
- 上线 12 个月内 DAU 50 万
- LTV > ¥120
- 国内 + 海外双线发行（中文 / 英文 / 日文）

## 2. 玩法设计

### 2.1 角色系统

玩家可招募的指挥官角色共 36 位，每位具备：

| 属性 | 范围 | 说明 |
|---|---|---|
| 攻击 | 50-500 | 影响战斗伤害 |
| 防御 | 30-300 | 影响承受伤害 |
| 速度 | 1-100 | 决定行动顺序 |
| 技能槽 | 2-4 | 可装备技能数 |
| 羁绊 | 0-10 | 角色间协同 |

#### 2.1.1 角色稀有度
- **SSR** (0.6%): 5 技能槽，全属性 80+
- **SR** (5.4%): 4 技能槽
- **R** (24%): 3 技能槽
- **N** (70%): 2 技能槽

### 2.2 战斗系统

回合制 + 战术地图。每回合双方舰队在 6x10 网格上行动，按速度排序。

技能示例（伪代码）：
```javascript
function activateSkill(caster, target, skill) {
  const baseDamage = caster.attack * skill.multiplier
  const mitigation = target.defense * 0.5
  const elemental = getElementalMultiplier(skill.element, target.element)
  const variance = 0.9 + Math.random() * 0.2
  const damage = Math.max(1, (baseDamage - mitigation) * elemental * variance)
  target.hp -= damage
  if (skill.statusEffect) applyStatus(target, skill.statusEffect)
}
```

### 2.3 经济系统

资源类型：晶体矿 / 暗物质 / 联盟积分 / 星币（付费货币）

- **付费深度**: 大 R 目标月消费 ¥3000+
- **付费广度**: 小 R 月卡 ¥30 / 月
- **零氪友好度**: 全部角色可通过游戏内"角色碎片"系统获取

## 4. 技术架构

- **客户端**: Unity 2022 LTS + C#
- **服务端**: Go 1.22 + 自研 ECS
- **数据库**: PostgreSQL 16 (主) + Redis 7 (缓存)
- **战斗服**: Agones (Kubernetes 游戏服务器编排)
- **匹配**: 自研 Glicko-2 评分
- **数据分析**: Kafka + ClickHouse + Grafana

### 4.1 性能指标
- 启动到首屏 ≤ 3 秒（中端 Android）
- 战斗帧率 ≥ 30 FPS
- 服务端单实例承载 5000 在线
- 同步延迟 ≤ 80ms

## 7. AI 辅助开发预算

> 这里就是 token-budget 工具要解决的场景。

预计在开发周期中使用 LLM 完成以下任务，需要预估每月 API 成本：

1. **代码生成**（前端 UI、服务端 API、ECS 系统）
   - 估算每日 500K input tokens + 50K output tokens
2. **角色剧情生成**（36 角色 × 平均 5000 字剧情 = 180K 字）
3. **文案本地化**（中英日三语互译，估计每月 2M tokens）
4. **代码评审与文档**
5. **Bug 复现与诊断**

需要对比：DeepSeek V4 Flash / GPT-5.4 / Claude Sonnet 4.6 / Qwen3.7-Max / GLM-4.6，选择最便宜的方案。

## 8. 风险评估

- **AI 成本失控**: 高风险 — 月度成本可能从 ¥500 到 ¥5000 浮动，需对账
- **服务端压力**: 中风险 — 战斗服扩容机制需要验证
- **付费失衡**: 中风险 — 大 R 与零氪差距需仔细调优
- **审查风险**: 低 — 内容审查由 SkyNet SDK 自动处理
